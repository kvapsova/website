{{/* home/video: the introductory talk, at the end of the community section. The poster shows the video's own YouTube thumbnail. It is fetched once, at build time, and served from this site as a webp, so a visitor's browser makes no request to YouTube or Google until they press play. The player (youtube-nocookie) is created on click. Thumbnail lookup, best first: maxresdefault, sddefault, hqdefault. If none can be fetched (offline build, video removed) the build only warns and the poster stays black with the play icon, as in the Figma frame. Without JavaScript the poster is a plain link to the video. Parameters: id YouTube video id title accessible title poster optional: path of an image under assets/ to use instead of fetching one Site param video_thumbnail_base (default https://i.ytimg.com/vi) can point at a mirror. */ -}} {{- $id := .Get "id" | default "UBppH7GqQTA" -}} {{- $title := .Get "title" | default "Cozystack 5 min Lightning Talk" -}} {{- $base := site.Params.video_thumbnail_base | default "https://i.ytimg.com/vi" -}} {{- $thumb := "" -}} {{- with .Get "poster" }} {{- with resources.Get . }}{{ $thumb = . }}{{ else }}{{ warnf "home/video: poster %q not found under assets/" . }}{{ end }} {{- end }} {{- if not $thumb }} {{- range slice "maxresdefault" "sddefault" "hqdefault" }} {{- if not $thumb }} {{- $url := printf "%s/%s/%s.jpg" $base $id . }} {{- with try (resources.GetRemote $url) }} {{- if not .Err }} {{- with .Value }}{{ if eq .MediaType.MainType "image" }}{{ $thumb = . }}{{ end }}{{ end }} {{- end }} {{- end }} {{- end }} {{- end }} {{- if not $thumb }}{{ warnf "home/video: no thumbnail could be fetched for %q, showing the plain poster" $id }}{{ end }} {{- end }} {{- $img := "" -}} {{- with $thumb }}{{ $img = .Process "webp q80" }}{{ end }}
